## 2. Picking a type for a column
Picking a value type for a column is important. It makes sure the right type of data is entered in the columns. Money always is numeric, Float stores with a tiny rounding error which could surface when added multiple values, whereas, numeric does not convert in binary fractions and stores exactly. 
Auto-incrementing surrogate is generated by using "generated always as identity", and it automatically gives the numbers to the rows, no need to type it ourselves.

## 4. NOT NULL vs UNIQUE
Not Null means it data can be repeated but a NULL cannot be added. and Unique means no duplicates can exist however NULLS can exist as NULLs are not cosidered as equals. A table can have more than one unique column.

## 5. FOREIGN KEY
FK column references other key column in another table It ensures every value in the column should already exist in the other table ( their key column) or be NULL. it will throw an error if tried to delete a parent row, if that parent row still has children pointing to it. It makes the tables relate to each other. the parent has to exist before the child, hence the particular order is necessary. however, the FK relation can be added later as well using ALTER table
